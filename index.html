A self-hosted WhatsApp REST API

GOWA (Go WhatsApp) is built for efficient memory use. One Go server sends and receives WhatsApp messages over HTTP, and can keep more than one account connected at the same time.

Features

The list below follows the project readme. The documentation and the readme describe the full HTTP API.

  • Multi-device and multi-account

    Connect and manage multiple WhatsApp accounts in a single server instance. Device-scoped calls take an X-Device-Id header or a device_id query parameter. When only one device is registered, it is the default.

  • Webhooks

    Forward received messages and other events to a webhook URL. Each device can set its own URL and event filter, or fall back to the global webhook. Requests can include an HMAC-SHA256 signature in X-Hub-Signature-256.

  • Web dashboard

    The dashboard lives in gowa-ui. The server downloads a release, checks its SHA-256 digest, caches it, and serves it at /.

  • MCP server

    The REST server exposes a Model Context Protocol endpoint at /mcp for AI agents and tools. Optional OAuth 2.1 is available for remote clients that cannot send a Basic Auth header. OAuth is off by default.

  • Chatwoot

    An optional Chatwoot integration can forward conversations and sync history. It stays off until CHATWOOT_ENABLED is set. Per-device configuration and a reply webhook are part of that integration.

  • Scheduled sends

    Schedule a supported send once, or repeat it daily, weekly, or monthly. Schedules survive restarts. List, pause, resume, or cancel them at /send/schedules. The readme says this does not guarantee exactly-once delivery.

Also in the readme

  • Send text, images, video, audio, files, stickers, contacts, locations, polls, and links over HTTP.
  • Follow newsletter channels, read their metadata and messages, search the directory, and download channel media.
  • Filter webhook events, sign them with a secret you generate, and skip selected chats or senders.
  • Basic Auth with multiple credentials, a custom linked-device name, and deployment under a subpath with --base-path.
  • Linux, macOS, and Windows are supported platforms. The project publishes ARM and AMD64 downloads.
  • An n8n community node is published as @aldinokemal2104/n8n-nodes-gowa.

Docker quick start

Docker avoids installing Go, FFmpeg, and libwebp on the host. The official image on Docker Hub is aldinokemal2104/go-whatsapp-web-multidevice. This is the production example from the project readme.

The container publishes port 3000. Open http://localhost:3000 on the machine running Docker.

Basic authentication is required when the server binds a non-loopback address. The default bind address is 0.0.0.0. Set credentials with --basic-auth or APP_BASIC_AUTH, with a username and password in every entry.

The same readme also documents the GitHub Container Registry image ghcr.io/aldinokemal/go-whatsapp-web-multidevice and Docker Compose examples. Start a Compose stack with docker compose up -d.
